# SERGDATA Workbench + AI-Knowledge — интеграционный патч

## Что добавляет

- Системный выбор папки проекта и раздельные системные диалоги выбора папки/файла.
- Адаптивный диалог базы знаний с внутренней прокруткой.
- Реестр внешних папок в `AI-Knowledge/sources.json`. Источники индексируются с ключами `@external/<id>/<relative-path>`; MCP `read_knowledge_file` разрешает чтение этих источников только через реестр.
- Управление `repositories.json`: просмотр, добавление, редактирование URL/имени, удаление записи без удаления локального клона.
- Отдельное клонирование и обновление репозитория. Обновление блокируется при локальных изменениях или несовпадении `origin`.
- Полный цикл через штатный `update-knowledge.ps1`: Git → Release Notes → инкрементальная индексация.
- Поиск по FTS5, просмотр содержимого найденного документа, статистика файлов/фрагментов/размера БД и журнал операций.
- Дополнительные подписи для английского режима интерфейса.

## Важные ограничения и гарантии

- Не изменяются схема SQLite и существующие таблицы; `knowledge.db` не входит в архив.
- Полная индексация автоматически не запускается при установке. Она запускается только кнопкой пользователя.
- Внешние источники не копируются в AI-Knowledge; сохраняются только их пути в `sources.json`.
- Отключение источника не удаляет его файлы и индексированные записи. MCP чтение уже проиндексированных документов остаётся разрешённым, пока запись источника присутствует в реестре.
- Удаление Git-репозитория из списка не удаляет клон и индекс.
- `update-knowledge.ps1` получил параметры `BasePath`, `PythonPath`, `NoPause`; значения по умолчанию совместимы с запуском из каталога AI-Knowledge.
- Скрипт полного обновления по-прежнему использует исходные проверки целостности и не использует `git reset --hard` или `git clean`.
- Архив не содержит `.env`, `.workbench`, credentials, Git-каталогов, SSH-ключей, профилей, `knowledge.db` или содержимого документов.

## Установка

1. Распакуй архив в отдельную временную папку.
2. Останови SERGDATA Workbench.
3. Запусти PowerShell от обычного пользователя (не от администратора) и выполни `install.ps1`.
4. Укажи корень Workbench и корень AI-Knowledge.
5. Скрипт создаст резервную копию семи изменяемых файлов в `%LOCALAPPDATA%\SERGDATA\backups\Knowledge-Integration-<timestamp>`, скопирует файлы и сверит SHA256.
6. Запусти Workbench и проверь локальный выбор папки/файла, RU/EN, внешний источник, поиск и статус.

## Откат

Останови Workbench и запусти `rollback.ps1`, указав папку резервной копии из шага установки. Откат восстанавливает только семь файлов, перечисленных в `manifest.json`.

## Рекомендуемая проверка после установки

1. В RU и EN открыть «Ещё → База знаний».
2. Проверить, что «Выбрать папку» открывает диалог выбора каталога, а «Выбрать файл» — диалог открытия файла.
3. Зарегистрировать небольшую тестовую папку вне AI-Knowledge, проиндексировать один текстовый файл, найти уникальную фразу и открыть документ.
4. Проверить выборочную индексацию существующего файла из `documents`.
5. Проверить репозиторий на тестовой копии: клон/обновление; специально грязный репозиторий должен получить отказ без изменения файлов.
6. Только после этого запускать полный цикл Git + Release Notes + индекс.
