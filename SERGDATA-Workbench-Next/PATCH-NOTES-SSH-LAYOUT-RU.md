# SERGDATA Workbench — Patch: SSH approval flow + responsive layout

## Что исправлено

### 1. SSH-подтверждение
- После постановки `ssh_run_command` в очередь агент немедленно завершает текущий инструментальный проход.
- Модель получает явное указание ждать подтверждения, не запускать локальный PowerShell как обходной путь и не заявлять об уже выполненном подключении.
- Сохраняется существующая очередь исполнения и существующий SSH-адаптер OpenSSH.
- Проверка host key остаётся строгой (`StrictHostKeyChecking=yes`); отключение проверки не добавлялось.

Важно: этот патч устраняет обнаруженный сценарий, когда модель сразу после постановки SSH-команды генерировала PowerShell fallback. Результат подтверждённого процесса по-прежнему фиксируется в истории Workbench. Автоматическое продолжение исходного tool-call после завершения фонового процесса не реализовано; после получения результата пользователь может попросить агента продолжить анализ.

### 2. Адаптивная ширина колонок
- Ширина боковых панелей ограничивается доступной шириной окна с сохранением минимальной рабочей ширины центральной области.
- При уменьшении окна сохранённые значения ширины не сбрасываются.
- Заголовок задачи переносится и не должен уходить за край центральной области.
- Панель действий верхней строки становится горизонтально прокручиваемой; кнопки остаются доступны, даже если не помещаются.
- Добавлены видимая полоса прокрутки и клавиатурный фокус для панели действий.
- На узких экранах используется одноколоночный режим.

## Установка

1. Остановить Workbench.
2. Сделать резервную копию текущей папки приложения.
3. Распаковать архив поверх исходников.
4. Не заменять `.env`, `.workbench`, SQLite, пользовательские проекты и виртуальное окружение.
5. Запустить `start.cmd`.

В архив не включены `.env`, `.workbench`, базы SQLite, `.venv`, кэш pytest и `__pycache__`.
