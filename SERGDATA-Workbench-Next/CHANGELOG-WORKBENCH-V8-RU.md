# SERGDATA Workbench v8 — Live Agent Activity

## Исправления

- Добавлено серверное состояние активности агента по ветке: подготовка, генерация модели, выполнение инструмента, ожидание защищённого ввода и ожидание подтверждения.
- `/api/chat/status` теперь возвращает не только факт активной задачи, но и её текущую фазу.
- Интерфейс опрашивает состояние во время активного запроса и обновляет историю сообщений без необходимости нажимать «Остановить».
- Compute показывает фазу текущей работы; таймер привязан к началу текущей фазы, а не ко всему времени агентного цикла.
- После запроса пароля или постановки SSH-команды на подтверждение Workbench больше не запускает лишнюю генерацию модели только ради сообщения «ожидается ввод/подтверждение».
- Результаты остановки фонового процесса теперь считаются подтверждёнными только после проверки терминального состояния процесса/рабочего потока.
- API остановки процесса возвращает `active`, `status`, `stopped` и сообщение; UI продолжает опрос, если процесс ещё завершает работу.
- Сохранено разделение отмены генерации модели и остановки отдельного SSH/PowerShell-процесса.

## Важные ограничения

- Ответы модели по-прежнему поступают после завершения отдельного вызова LM Studio: потоковая передача токенов из LM Studio в браузер не реализована в этой версии. При этом фазы агентного цикла и уже сохранённые сообщения/результаты инструментов обновляются во время запроса.
- Успешная парольная авторизация SUB зависит от правильности сохранённого пароля и серверной политики SSH. Патч не обходит `known_hosts` и не меняет `sshd_config`.
