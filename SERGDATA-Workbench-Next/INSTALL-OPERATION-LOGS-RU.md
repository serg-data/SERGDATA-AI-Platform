# Кнопка «Логи» — SERGDATA Workbench

## Что добавлено
- Кнопка «Логи» в верхней панели.
- Отдельное окно журнала Git / Releases / AI-Knowledge.
- Автообновление каждые 1,5 секунды, пока окно открыто.
- Отображение статуса, этапа, источника, времени и кода завершения.
- Копирование журнала в буфер обмена.

Журнал использует существующее состояние операции `/api/knowledge/status`; логика индексации, Git, Releases, MCP и база данных не меняются.

## Установка
1. Остановить SERGDATA Workbench.
2. Сделать резервные копии `static/index.html` и `static/app.js`.
3. Распаковать содержимое архива с сохранением структуры поверх корня Workbench.
4. Запустить Workbench и обновить страницу сочетанием Ctrl+F5.
5. Нажать «Логи» в верхней панели.

Окно показывает текущий или последний вывод операции AI-Knowledge в рамках текущего запуска Workbench. Это не общий системный журнал Uvicorn и не журнал сообщений модели.
