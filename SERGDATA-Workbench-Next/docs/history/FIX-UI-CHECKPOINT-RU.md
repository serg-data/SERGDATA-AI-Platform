# Исправление верхней панели и контрольной точки

## Что изменено

- Верхняя панель действий теперь переносит кнопки на следующие строки вместо горизонтального прокручиваемого контейнера. Это предотвращает обрезание выпадающего меню «Настройки агента» и делает «Сохранить точку» доступной без горизонтальной прокрутки.
- Высота верхней панели может увеличиваться при переносе элементов; остальная компоновка рабочего пространства не меняется.
- Обработчик «Сохранить точку» проверяет наличие активной ветки, блокирует повторное нажатие на время запроса, показывает состояние «Сохраняю…» и возвращает кнопку в исходное состояние при успехе или ошибке.
- Обновлены версии CSS/JS в HTML, чтобы браузер не использовал старые файлы из кеша.

## Проверки

- `node --check static/app.js` — успешно.
- `python -m pytest -q` — 164 теста пройдены.
- Проверены статические условия CSS/JS для переноса панели и состояния контрольной точки.
- Полноценный браузерный клик-тест в пользовательском Chrome не выполнялся.

## Установка

1. Останови Workbench через Ctrl+C.
2. Сделай резервную копию папки `F:\AI-Projects\visual-site` или фактической папки установки.
3. Распакуй архив поверх существующей папки проекта.
4. Не заменяй `.env` и `.workbench`; сохрани SQLite, DPAPI credentials, загрузки и пользовательские данные.
5. Запусти `start.cmd`.
6. В Chrome выполни Ctrl+F5.

Патч затрагивает только `static/index.html`, `static/style.css`, `static/app.js` и этот файл с описанием изменений.
