# Отчёт: автономность Sandbox — тестовая копия

Дата: 2026-11-05

## Изменения
Добавлен пустой режим Sandbox, исправлен diff для пустой области, усилена проверка выбранных путей и уточнены инструкции агента для автономной работы внутри Sandbox. Существующие инструменты Windows/SSH и механизм подтверждения внешних действий не изменялись.

## Проверки
- `python -m compileall -q workbench` — успешно.
- `python -m pytest -q tests/test_sandbox.py` — 9 passed.
- `python -m pytest -q` — 188 passed.
- Полный прогон ранее в этой среде показывал нестабильные timing-тесты ProcessRegistry; повторный полный прогон завершился успешно. Это остаётся потенциально flaky областью.

## Что доказано
- Пустая Sandbox создаётся без копирования исходных файлов.
- Файлы, созданные внутри пустой Sandbox, не меняют исходный каталог.
- Diff правильно показывает добавленные файлы и не объявляет весь источник удалённым.
- Абсолютные и symlink-пути при выборочном копировании отклоняются.
- Режим `copy` сохранён.

## Что НЕ доказано
- Реальная изоляция ОС отсутствует.
- Runner не защищён от вредоносного Python-кода: pytest выполняется на хосте.
- Нельзя заявлять о полноценной автономности в живом UI/LM Studio без запуска этой тестовой копии на Windows и сквозного теста с моделью.
- Windows, SSH и сетевые действия не запускались.

## Итог
Частичная реализация и локальные тесты пройдены. Полноценное Sandbox Lab с изоляцией ОС и подтверждённым end-to-end циклом — НЕ ПРОЙДЕНО.
