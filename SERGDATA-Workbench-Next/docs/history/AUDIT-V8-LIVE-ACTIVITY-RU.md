# Аудит SERGDATA Workbench v8

## Подтверждённые изменения исходников

- В `main.py` добавлен реестр `CHAT_ACTIVITY` с состоянием на ветку; `/api/chat/status` отдаёт фазу и деталь.
- `Agent` сообщает фазы `preparing`, `model_generation`, `tool_running`, `waiting_input`, `waiting_approval`.
- `static/app.js` опрашивает статус раз в 1.2 секунды во время активного запроса и перечитывает сохранённую историю. Позиция прокрутки сохраняется, если пользователь не находится у нижнего края.
- Ожидание защищённого ввода/подтверждения теперь формируется локальным сообщением Workbench без дополнительного запроса к LM Studio.
- Таймер Compute рассчитывает время текущей фазы по `updated_at`.
- `ProcessRegistry.stop()` ожидает завершения процесса/потока и возвращает успех только при терминальном статусе.
- Endpoint остановки процесса возвращает фактический статус; UI продолжает опрос, если процесс ещё активен.

## Проверки

- `PYTHONPATH=. python -m pytest -q`: **164 passed**.
- `python -m compileall -q .`: успешно.
- `node --check static/app.js`: успешно.
- ZIP integrity: проверяется при сборке.

## Что не подтверждено автоматическими тестами

- Реальное прекращение генерации конкретной сборки LM Studio/Neohorse на Windows.
- Фактическая авторизация SUB: она зависит от сохранённого секрета, правильности пароля и разрешённой на сервере парольной авторизации root.
- Поведение перетаскивания разделителя на физическом браузере пользователя.
- Потоковая выдача отдельных токенов модели: в v8 не реализована. Интерфейс обновляет историю и фазы агентного цикла, но текст ответа появляется после завершения вызова модели.
