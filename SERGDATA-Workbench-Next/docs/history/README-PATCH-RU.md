# SERGDATA Workbench — безопасная обработка пустого content при наличии reasoning_content

## Что исправлено
- Основной цикл чата и продолжение после подтверждения используют только `message.content` как пользовательский текст.
- Если `content` пуст, но `reasoning_content` заполнен, Workbench не показывает внутреннее reasoning. Вместо пустого ответа он сообщает, что модель завершила генерацию, но не вернула видимый текст.
- Если оба поля пусты, пользователь также получает явное сообщение, а не молчание.
- Native tool calls и текстовый формат вызовов инструментов продолжают разбираться только из `content`; reasoning не исполняется и не трактуется как команда.
- Обычный `content` имеет приоритет и остаётся без изменений.

## Установка
1. Остановить Workbench.
2. Сделать копии трёх перечисленных файлов из своей рабочей папки.
3. Распаковать содержимое `files/` из этого патч-архива поверх корня Workbench, сохранив структуру каталогов.
4. Запустить Workbench и проверить обычный ответ, вызов инструмента и сценарий продолжения после подтверждения.
5. Если возникнет проблема — вернуть три резервные копии.

Патч подготовлен на копии архива. Исходный ZIP и рабочая папка пользователя не изменялись.
