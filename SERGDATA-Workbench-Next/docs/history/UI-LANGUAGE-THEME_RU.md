# Обновление интерфейса: язык и тема

Добавлены глобальные настройки интерфейса SERGDATA Workbench:

- переключение языка RU / EN;
- переключение тёмной и светлой темы;
- сохранение выбранных параметров в localStorage браузера;
- применение настроек после перезагрузки страницы;
- переводы основных элементов навигации, действий, диалогов, подсказок и подписей;
- новые версии CSS/JS в cache-busting ссылках.

Настройки относятся только к интерфейсу Workbench и не меняют язык ответов модели, содержимое пользовательских сообщений, системные настройки или данные проектов.

Проверки:
- `node --check static/app.js` — успешно;
- `python -m compileall -q main.py workbench tests` — успешно;
- `PYTHONPATH=. pytest -q --ignore=tests/test_autonomy_processes.py` — 53 passed.

Ограничение проверки: интерактивный браузерный прогон в Windows с реальным LM Studio не выполнялся. Перевод покрывает основные элементы интерфейса; отдельные динамические сообщения, названия инструментов и текст модели могут оставаться на языке исходного сообщения.
