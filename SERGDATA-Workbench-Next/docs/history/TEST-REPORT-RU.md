# Отчёт проверки интеграционного патча

Дата сборки: 07.11.2026

## Выполнено в среде сборки

- `python -m py_compile` для `main.py`, `kb.py`, `server.py`, `document_readers.py`, `release_sync.py` — успешно.
- `node --check static/app.js` — успешно.
- Разбор `static/index.html` стандартным HTMLParser — успешно.
- Индексация тестового внутреннего файла — успешно.
- Индексация тестового внешнего файла из папки вне AI-Knowledge — успешно.
- Повторный запуск по внешнему файлу проверен на сохранении существующей записи и корректном поведении инкрементального индекса.
- Проверено, что внешнему документу назначается стабильный ключ `@external/<source-id>/<relative-path>`.
- MCP `read_knowledge_file` проверен на тестовом внешнем документе с заглушкой FastMCP — файл прочитан через реестр источников.
- Повторная индексация внешнего файла проверена: файл распознан как неизменённый, новая запись не создана.
- В архиве проверено отсутствие `knowledge.db`, `.env`, `.workbench`, Git-данных и SSH-материалов.
- Поиск использует существующую FTS5-таблицу `chunk_search`; просмотр использует содержимое существующей таблицы `files`.

## Не выполнено в среде сборки

- Импорт и запуск полного Workbench: отсутствует зависимость `openai` (поэтому приложение и его HTTP API не запускались).
- Запуск PowerShell `update-knowledge.ps1`: Windows PowerShell / PowerShell 7 в среде сборки отсутствует.
- Проверка нативных диалогов Windows, размеров окон в реальном браузере и RU/EN визуально — требуется Windows desktop.
- Проверка на рабочей пользовательской базе `knowledge.db` не проводилась. Файл базы не открывался и не изменялся.

## Вывод

Статическая проверка исходников и изолированный тест внешней индексации/чтения пройдены. Перед запуском полного обновления на рабочем компьютере обязательна проверка интерфейса и тестового репозитория. Полный PowerShell/Git цикл в этой среде не подтверждён.
