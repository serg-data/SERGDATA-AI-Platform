## Важное ограничение безопасности
Sandbox Lab в этой версии — изолированная файловая рабочая копия, но не изоляция уровня ОС. Процессы `pytest`/`ruff`/`compile` запускаются локально от имени пользователя Workbench и теоретически могут обращаться к другим ресурсам компьютера. Не запускайте в ней недоверенный код. Для настоящей изоляции исполнения потребуется отдельный backend на Windows Sandbox или контейнере с ограничениями ресурсов, сети и томов.

## Доработка Shell-проверок

- `sandbox_run_check` дополнен статическими проверками `sh -n`, `bash -n` и `shellcheck`.
- Для Shell-проверки требуется относительный путь к файлу внутри песочницы.
- Запуск произвольных `.sh`-скриптов через этот инструмент по-прежнему запрещён.
- Проверки выполняются без `shell=True`; путь проверяется средствами SandboxManager.
- Добавлены тесты корректного/ошибочного синтаксиса и отказа при небезопасном пути.
