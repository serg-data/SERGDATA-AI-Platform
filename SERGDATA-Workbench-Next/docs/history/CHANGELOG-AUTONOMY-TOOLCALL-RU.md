# Изменения: автономный цикл Tool Calling

- Добавлена совместимость с текстовым форматом вызовов инструментов Neohorse/Qwen, если LM Studio не возвращает нативное поле `tool_calls`.
- Добавлена строгая проверка имени инструмента и параметров по опубликованной схеме; неизвестные/неполные вызовы не исполняются.
- Адаптер подключён как к основному циклу агента, так и к возобновлению после пользовательского ввода/подтверждения.
- Повторные идентичные вызовы используют ранее полученный результат, если он существует, вместо остановки всего цикла.
- `sandbox_run_check` принимает безопасные аргументы pytest, включая `test_app.py -v`; флаги и пути ограничены.
- UI различает повторно использованный результат.
- Добавлены тесты парсинга, отказа для неверных вызовов и сквозного цикла «текстовый вызов → исполнение → продолжение модели».
