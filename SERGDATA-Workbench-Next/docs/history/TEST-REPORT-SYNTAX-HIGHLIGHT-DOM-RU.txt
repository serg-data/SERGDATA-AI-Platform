Браузерный тест проверяет SH/Bash, Python, JSON, JavaScript и PowerShell.
Для каждого блока сравниваются innerText, textContent и значение,
передаваемое кнопкой копирования. Дополнительно проверяются наличие
токенов подсветки и отсутствие утечки атрибутов class="tok-*" в текст.
Также проверяются специальные символы <, >, &, кавычки и последовательность
</script> как обычное содержимое исходного кода.

ОГРАНИЧЕНИЕ
-----------
Проверка сделана на выделенном Chromium DOM harness с функциями из
фактического static/app.js. Живой пользовательский браузер и LM Studio
не запускались. После установки требуется контрольная проверка в браузере
пользователя с подтверждением runtime marker.
