НОВОЕ ПОВЕДЕНИЕ
Для staged deletion (Git porcelain v2 XY = D.) доступны две отдельные операции:
- «Восстановить из HEAD» — восстанавливает точную версию текущего локального коммита и очищает staged deletion.
- «Скачать заново из upstream» — выполняет fetch только настроенной upstream-ветки и восстанавливает только выбранный файл. Перед заменой существующий физический файл копируется в .doctor-quarantine.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
- Ветка и остальные файлы репозитория не переключаются и не перезаписываются.
- Если upstream содержит другую версию файла, операция останавливается без замены. В таком случае сначала восстанови файл из HEAD, затем запусти штатное полное обновление репозитория: оно безопасно обновит всю ветку.
- Если файл физически отсутствует, резервировать нечего; исходная версия остаётся в Git-объектах.
- Операция запрещена для symlink, каталога, untracked-файла, репозитория без настроенного upstream и во время активной индексации/синхронизации.
