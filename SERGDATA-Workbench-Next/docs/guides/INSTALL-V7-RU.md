# Установка SERGDATA Workbench v7

1. Полностью останови Workbench (`Ctrl+C` в окне `start.cmd`).
2. Сделай резервную копию папки проекта.
3. Распакуй содержимое архива поверх `F:\SERGDATA-Workbench-Next`.
4. **Не удаляй и не заменяй** существующие `.env` и `.workbench`. В архиве v7 их нет намеренно.
5. Запусти `start.cmd`.
6. Открой `http://127.0.0.1:8787` и обнови страницу `Ctrl+F5`.

## Что исправлено
- Различаются DPAPI-секрет, временный секрет текущего сеанса и отсутствующий секрет.
- Ошибка отказа SSH-аутентификации SUB отображается отдельно от отсутствующего секрета.
- Остановка профильного SSH закрывает активный Paramiko client/channel.
- Остановка Windows-процесса завершает дерево процессов и проверяет завершение.
- Остановка модели работает и во время продолжения после защищённого ввода/результата инструмента.
- Разделитель панели выполнения имеет 14 px область захвата и сохраняет размер.

## Проверка SUB
После установки сначала посмотри статус профиля SUB. Если написано «пароль доступен только до перезапуска», включи флажок «Сохранить через DPAPI» при следующем сохранении/обновлении профиля, если хочешь сохранять его между перезапусками.
Затем выполни только безопасную команду `hostname` через профиль SUB. Если сервер ответит `AuthenticationException`, это означает, что сервер отверг переданный пароль; проверь пароль и серверную политику SSH для root. Не отключай проверку host key.

## Проверка остановки
- Запусти длительную безопасную команду через SSH-профиль и нажми «Остановить» в карточке процесса.
- Дождись статуса `stopped`.
- Отдельно запусти долгую генерацию модели и нажми Stop у поля отправки. Это остановка модели, не SSH-процесса.

Полный аудит и ограничения тестирования см. `AUDIT-V7-SSH-STOP-RESIZE-RU.md`.
