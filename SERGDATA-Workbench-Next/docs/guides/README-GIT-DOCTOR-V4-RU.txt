SERGDATA Workbench — Git Doctor v4

Установка:
1. Полностью остановить Workbench.
2. Сделать резервную копию F:\SERGDATA-Workbench-Next.
3. Распаковать содержимое архива в корень F:\SERGDATA-Workbench-Next с заменой файлов.
   В архиве используются только: main.py, static\app.js, static\style.css.
4. Запустить Workbench заново и открыть «База знаний» → «Git Doctor · диагностика».

Что изменено:
- Диагностика читает Git status в NUL-разделённом формате, корректно обрабатывая пробелы,
  переводы строк, кавычки и необычные Unicode-символы в именах файлов.
- Отдельно показывает отслеживаемые изменения, неотслеживаемые файлы, переименования,
  конфликты, удаления и подозрительные имена (в том числе Unicode Private Use/control chars
  и имена с характерными фрагментами случайно вставленного консольного текста).
- Неотслеживаемые файлы показываются все, подозрительные помечаются отдельно.
- Добавлено отображение upstream, если он настроен.
- Окно «База знаний» расширено до 1040 px (в пределах ширины экрана); кнопки переносятся,
  горизонтальная прокрутка окна не требуется.

Безопасность:
- Только читающие команды Git: rev-parse, status, branch.
- Нет add/reset/restore/checkout/clean/pull/fetch/commit и удаления файлов.
- Правая Git-панель и её API не менялись.
- База знаний, индекс и repositories.json не изменяются.

После установки сначала проверьте systemd и passwall2. Ничего не исправляйте автоматически:
эта версия предназначена для диагностики и выдачи понятного отчёта.
