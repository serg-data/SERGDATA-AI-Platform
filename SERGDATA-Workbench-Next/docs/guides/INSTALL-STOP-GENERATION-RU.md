# SERGDATA Workbench — исправление состояния кнопки «Остановить»

## Что исправлено

Предыдущая версия добавила серверную защиту от двух одновременных запросов в одной ветке, но не восстанавливала состояние кнопки после обновления страницы. В итоге сервер мог продолжать запрос, браузер показывал «Отправить», а новая отправка получала HTTP 409.

Эта версия:
- добавляет серверный статус активного запроса по ветке;
- восстанавливает кнопку «Остановить» при открытии задачи/ветки и после обновления страницы;
- при HTTP 409 синхронизирует UI и сохраняет текст сообщения, которое не было отправлено;
- после нажатия «Остановить» ожидает освобождения блокировки ветки до 8 секунд; если запрос ещё завершает работу, сообщает об этом и сохраняет активное состояние кнопки.

## Установка
1. Остановить Workbench через Ctrl+C.
2. Сделать резервную копию папки проекта.
3. Распаковать архив поверх `F:\SERGDATA-Workbench-Next`.
4. Не заменять `.env`, `.workbench`, SQLite, миграции и SSH-ключи.
5. Запустить `start.cmd` и обновить страницу Ctrl+F5.

## Проверка
1. Открыть ветку. Если сервер ещё обрабатывает запрос, кнопка должна сразу показать «Остановить».
2. Нажать «Остановить». Должно появиться сообщение о фактическом завершении или о том, что сервер ещё завершает запрос.
3. Дождаться возврата кнопки «Отправить».
4. Отправить короткий новый запрос и убедиться, что он выполняется.

Остановка генерации не подтверждает и не запускает SSH-команды. Запущенные процессы PowerShell/SSH останавливаются отдельной кнопкой в панели выполнения.
