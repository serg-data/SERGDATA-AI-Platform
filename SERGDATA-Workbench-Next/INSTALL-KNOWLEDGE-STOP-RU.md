# Безопасная остановка AI-Knowledge в SERGDATA Workbench

## Поведение кнопки «Закрыть»
- Если операция не выполняется: закрывает окно.
- Если операция выполняется: первое нажатие запрашивает остановку процесса индексации / PowerShell вместе с дочерними процессами.
- Пока идёт остановка, кнопка показывает «Остановка…» и недоступна.
- Когда процесс завершён, повторное нажатие закрывает окно.

Остановка не выключает сервер Workbench и не удаляет уже записанные документы. Операция фиксируется со статусом `stopped`, а не как успешная. Текущая транзакция SQLite при аварийном прерывании должна быть восстановлена SQLite при следующем открытии; уже завершённые транзакции остаются сохранёнными. После остановки рекомендуется проверить целостность базы перед новым полным запуском.

## Установка
1. Дождаться, пока текущая операция закончится, либо остановить её существующими средствами. Не заменять файлы работающего сервера.
2. Остановить сервер Workbench.
3. Скопировать резервно `main.py`, `static/index.html`, `static/app.js`.
4. Распаковать ZIP-патч в корень рабочей папки с сохранением структуры.
5. Запустить Workbench и выполнить Ctrl+F5.
6. Во время тестового запуска нажать «Закрыть» один раз: операция должна остановиться, окно останется открытым. После появления статуса остановки нажать «Закрыть» ещё раз.

Патч управляет только дочерним процессом, который Workbench запустил для текущей операции. Он не завершает сам Workbench, LM Studio или другие независимые процессы.
