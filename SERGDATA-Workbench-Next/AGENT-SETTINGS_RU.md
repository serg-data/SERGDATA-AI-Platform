# Настройки агента SERGDATA Workbench

Откройте меню «Настройки агента» в верхней панели.

## Параметры
- Размер контекста: 8 192–262 144 токена. Реальный предел дополнительно ограничивается возможностями выбранной модели в LM Studio.
- Максимум этапов модели: 1–32. Этап — один ответ модели; он может содержать несколько вызовов инструментов.
- Максимум вызовов инструментов: 1–64 на один пользовательский запрос.
- Вариативность (temperature): 0–1. Для инженерных задач обычно 0–0,2.
- Тайм-аут запроса: 30–600 секунд.

## Хранение и применение
Настройки хранятся в SQLite `app_settings` внутри `.workbench/workbench.sqlite3`. Они не записываются в `.env`, не теряются при перезапуске и применяются к следующему запросу модели. Существующие `.env` значения используются для первичной настройки базы при первом запуске; после сохранения в интерфейсе пользовательские настройки имеют приоритет.

Настройки общие для всего экземпляра Workbench, а не отдельные для проекта. Уровень автономности по-прежнему настраивается отдельно в параметрах проекта.

## Ограничения
- Увеличение лимита контекста не увеличивает физическое контекстное окно модели; Workbench использует меньший из доступных пределов.
- Лимит вызовов инструментов ограничивает суммарное количество вызовов за один запрос.
- Тайм-аут задаёт время ожидания ответа LM Studio, но не меняет тайм-ауты отдельного локального процесса PowerShell.
- Температура может игнорироваться некоторыми моделями/серверами LM Studio.
