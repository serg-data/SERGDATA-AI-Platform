# SERGDATA Workbench — интеграция базы знаний с ProcessRegistry

## Что исправлено

- Выборочная индексация и полная синхронизация запускаются через общий `workbench.processes.ProcessRegistry`.
- API `POST /api/knowledge/stop` останавливает только текущую задачу базы знаний через общий реестр.
- Обработана гонка, когда запрос остановки приходит до того, как дочерний процесс успел зарегистрироваться.
- Чтение stdout/stderr поддерживает и `\n`, и `\r`, поэтому обновления прогресс-бара доступны без ожидания следующей строки.
- В окне базы знаний первое нажатие «Остановить / закрыть» останавливает операцию; после её завершения следующее нажатие закрывает окно.
- Добавлена кнопка «Логи» с просмотром состояния и вывода текущей операции, автообновлением и копированием.
- Существующий Git Doctor, маршруты Git, внешние источники и код SQLite не заменялись.

## Установка

1. Полностью остановить Workbench.
2. Сделать копию файлов `main.py`, `workbench/processes.py`, `static/index.html`, `static/app.js`.
3. Распаковать содержимое ZIP в корень `F:\SERGDATA-Workbench-Next` с заменой четырёх файлов.
4. Запустить Workbench обычным способом.
5. Обновить страницу сочетанием `Ctrl+F5`.
6. Открыть «База знаний», запустить небольшую выборочную индексацию и проверить кнопку остановки. Первое нажатие останавливает задачу, повторное закрывает окно.
7. Проверить кнопку «Логи» в верхней панели.

Патч не содержит и не заменяет `.workbench`, `.env`, SQLite-базы, конфигурацию AI-Knowledge или Git-клоны.

## Откат

Остановить Workbench и вернуть четыре файла из резервной копии, сделанной перед установкой. Затем запустить Workbench и выполнить `Ctrl+F5`.
