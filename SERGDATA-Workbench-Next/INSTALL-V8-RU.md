# Установка SERGDATA Workbench v8

1. Останови Workbench через `Ctrl+C` в окне запуска.
2. Сделай резервную копию папки проекта.
3. Распакуй архив поверх `F:\SERGDATA-Workbench-Next`.
4. Не заменяй `.env` и `.workbench` — пользовательская база, DPAPI credentials и загрузки должны остаться на месте. Эти данные не входят в архив.
5. Запусти `start.cmd`.
6. Обнови страницу Workbench через `Ctrl+F5`.

## Проверка после установки

1. Отправь запрос, который вызывает инструмент. История должна обновляться до завершения всего агентного цикла.
2. При постановке SSH-команды на подтверждение Compute должен перейти в состояние ожидания, а видеокарта не должна продолжать лишнюю генерацию только ради промежуточного сообщения.
3. При запросе секрета Compute должен показать «Ввод»; поле секрета остаётся отдельным и не перерисовывается опросом истории.
4. Запусти длительную PowerShell-команду в панели выполнения и нажми её отдельную кнопку «Остановить». Интерфейс должен показывать «Останавливаю…» до фактического завершения процесса.
5. Проверь остановку самой генерации через кнопку Compute.

## Безопасность

Не копируй в архив `.env`, `.workbench`, `credentials.dpapi`, SQLite-файлы, приватные SSH-ключи, пароли или токены. Не отключай строгую проверку SSH host key.
