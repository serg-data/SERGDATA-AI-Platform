# Интеллектуальный перенос контекста — обновление

## Что делает перенос

- Кнопка «Продолжить в новой задаче» запускает отдельный вызов выбранной модели LM Studio.
- Модель формирует компактное инженерное резюме на русском: цель, подтверждённая архитектура, важные пути/функции, решения и причины, фактические проверки, изменения, ошибки/ограничения и следующий конкретный шаг.
- Резюме сохраняется в памяти новой задачи. Новая задача создаётся в том же проекте и автоматически получает постоянную память проекта при формировании следующих запросов.
- Исходная задача, ветка, сообщения и контрольные точки не изменяются. Расход токенов на генерацию резюме учитывается как отдельный вызов `memory_summary` в исходной ветке, если LM Studio возвращает usage.
- В пакет включаются сведения об источнике и правила проверки реального состояния файлов.
- Названия и заметки вложений передаются модели как справочная информация; сами файлы не копируются и не перемещаются.

## Ограничение размера запроса

Для предотвращения чрезмерного запроса передаются максимум 80 сообщений: первые 20 и последние 60. Если история длиннее, вставляется явная отметка о пропуске промежуточных сообщений. Сохранённая память задачи и ветки также передаётся модели. Текст каждого сообщения ограничен 3000 символами. Это ограничение нужно учитывать, если старая история не была ранее сжата в памяти.

## Поведение при ошибке

Если LM Studio недоступна, модель не отвечает или возвращает пустое резюме, новая задача не создаётся. API возвращает ошибку, исходная задача остаётся нетронутой.

## Проверки

Проверки синтаксиса и тесты перечислены в итоговом сообщении только после фактического запуска в среде сборки. Полный запуск Windows + LM Studio требует отдельной проверки на компьютере пользователя.
