# Установка Compute UI v5 — горизонтальная кнопка

1. Останови Workbench (`Ctrl+C` в окне запуска).
2. Сделай резервную копию проекта.
3. Распакуй архив поверх `F:\\SERGDATA-Workbench-Next`.
4. Не заменяй `.env` и `.workbench` (в архиве их нет).
5. Запусти `start.cmd` и обнови страницу через `Ctrl+F5`.

## Что изменилось
Кнопка Compute теперь однострочная: индикатор, `Compute`, таймер и `Стоп` расположены горизонтально. Убрана вторая строка, из-за которой кнопка визуально росла вверх. На широком экране ширина во время генерации около 150 px; высота остаётся вровень с полем ввода. На узких экранах ширина адаптивно уменьшается.

Это только изменение интерфейса. Логика генерации, остановки и SSH не менялась.
