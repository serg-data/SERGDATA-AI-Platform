Выполнение · PowerShell / SSH
Команды модели выполняются только после подтверждения. Запуск от имени текущего пользователя, без повышения прав; рабочая папка — корень выбранного проекта.
Защищённый ввод пользователя
Пароли, PIN, OTP и токены отправляются отдельно и не попадают в историю чата. Постоянное сохранение доступно через Windows DPAPI текущей учётной записи.
