# Исправление двух действий верхней панели

## Что изменено

1. **Настройки агента**
   - При открытии панель настроек временно переносится непосредственно в `document.body`.
   - Позиция вычисляется относительно кнопки `summary`, поэтому горизонтальная прокрутка `.top-actions` больше не обрезает панель.
   - Состоянием открытия по-прежнему управляет нативный `<details>`.
   - Закрытие: повторное нажатие на summary, клик вне меню или Escape.
   - Позиция обновляется при прокрутке и изменении размера окна.

2. **Сохранить точку**
   - Добавлена защита от повторного нажатия.
   - Во время запроса кнопка показывает «Сохраняю…» и становится недоступной.
   - Под кнопкой отображается этап формирования контрольной точки.
   - Успешный результат, уже актуальная память и ошибка API выводятся в статусе и toast.
   - Ошибка обновления статистики не маскирует успешное сохранение.

3. Обновлена версия CSS в URL для принудительного сброса кэша браузера.

## Границы изменения

Не изменялись SSH, DPAPI, база данных, агентный цикл, серверный маршрут контрольных точек, память задач/проектов и остальные кнопки верхней панели.

## Проверки

- `node --check static/app.js` — успешно.
- `python -m py_compile main.py` — успешно.
- `PYTHONPATH=. pytest -q` — 164 passed.
- Дополнительно проведён браузерный smoke-test портала меню и состояний кнопки сохранения с имитацией успешного/ошибочного ответа API.
