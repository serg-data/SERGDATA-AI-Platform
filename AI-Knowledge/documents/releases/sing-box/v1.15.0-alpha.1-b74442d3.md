## :memo: Release Notes

* Implement fully functional `auto_redirect` for Android **1**
* Add `on_demand` endpoint option **2**
* Add cache file write buffering **3**
* Fixes and improvements

**1**:

`auto_redirect` is now fully supported on Android through the root service of the graphical client or a root shell.

See [TUN](https://sing-box.sagernet.org/configuration/inbound/tun/#auto_redirect).

**2**:

Allow the endpoint to be disconnected when necessary.

See [WireGuard](https://sing-box.sagernet.org/configuration/endpoint/wireguard/#on_demand), [Tailscale](https://sing-box.sagernet.org/configuration/endpoint/tailscale/#on_demand), [OpenVPN Client](https://sing-box.sagernet.org/configuration/endpoint/openvpn-client/#on_demand) and [OpenConnect](https://sing-box.sagernet.org/configuration/endpoint/openconnect/#on_demand).

**3**:

Changes to the cache file are now collected in a write buffer and committed in one transaction when the buffer is full, on memory pressure, or when sing-box exits.

See [Cache File](https://sing-box.sagernet.org/configuration/experimental/cache-file/#buffer_size).
