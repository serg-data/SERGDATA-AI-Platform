## Описание релиза

## 🚀 MASQUE, XDRIVE, Xray-core v26.10.10 & Node Sync

- 🛰️ **MASQUE** — a new protocol and transport for inbounds and outbounds, and the WARP modal can now register WARP over MASQUE.
- ☁️ **XDRIVE transport** — tunnel traffic through files in Google Drive, a local folder or any templated HTTP storage API.
- ⚙️ **Xray-core v26.10.10** — Lua DNS and routing scripts, new TUN and finalmask options, and stored configs migrate to the new shapes on their own.
- 🔗 **Node sync** — master pushes reach every node, a reset node can no longer wipe the hub's clients, and client edits on node inbounds no longer drop connections.
- 🧱 **Configs that would stop Xray are refused** — Shadowsocks-2022 keys and ciphers, mask passwords and storage settings Xray cannot run are rejected when you save.
- 📡 **Port hopping restored** — Hysteria and XHTTP clients hop ports again through the `udphop` mask.
- 🛡️ **Sandboxed systemd service** — the panel now runs with a reduced capability set and read-only system directories.
- 🔄 **Safer updates** — the database migration finishes before the service starts, and an update no longer touches your TLS setup.
- 🐘 **PostgreSQL 18** — new local database installs get the current major version from the official PGDG repository.

## ⚠️ Before you upgrade

### Action required
- Several node fixes run on the node itself: in-place client updates (no dropped connections), applying master pushes on admin-token nodes, and hosting MASQUE inbounds. A node on an older release keeps the old behavior, and placing a MASQUE inbound on it is refused — **do this:** upgrade every node, not only the master.
- Xray-core v26.10.10 checks outbound TLS against its bundled Mozilla roots instead of the OS certificate store — **do this:** on any outbound to a server signed by a privately installed CA, turn on *Use system CA* in that outbound's TLS settings.
- JSON subscriptions now send port hopping as the `udphop` mask (needs Xray-core 26.9.9+) and xdns masks in the `names`/`addrs` shape (needs Xray-core 26.10.10+) — **do this:** ask users of port hopping or xdns to update their client apps to a build on Xray-core 26.10.10 or newer.
- On systemd installs the service is now sandboxed: `/usr`, `/boot`, `/etc`, `/home` and `/root` are read-only except the panel's own DB, bin and log folders — **do this:** if the panel or Xray must write anywhere else under those trees, add the path with `ReadWritePaths=` in your own drop-in (`/etc/systemd/system/x-ui.service.d/20-local.conf`). After you change an `XUI_*_FOLDER` value in `/etc/default/x-ui`, re-run the update so the generated drop-in picks it up.

### Automatic — no action needed
- At first start, stored xdns finalmasks are rewritten to `names`/`addrs`. Legacy `quicParams.udpHop` on client-side configs (hosts, the subscription's global finalmask, cached outbound subscriptions, template outbounds) becomes a `udphop` mask. Inbounds keep `udpHop` as the advertised port range. Each rewrite runs once, and a failure stops the panel from starting.
- Shadowsocks-2022 inbounds on `2022-blake3-chacha20-poly1305` move to `2022-blake3-aes-256-gcm`, and their 32-byte keys stay valid. Server keys of the wrong size for their method are replaced. Neither kind of inbound could start before. A failure stops the panel from starting.
- `install.sh` and `update.sh` install the hardened unit and regenerate `x-ui.service.d/10-xui-sandbox.conf` from your `XUI_*` folders on every run. The seccomp filter is added only on systemd 239 or newer, and on older systemd the scripts list the protections it lacks. A folder path containing whitespace is left out with a warning, and a failed refresh is only a warning.
- A stored report or LDAP sync schedule that no longer parses falls back to the job's default, with a warning in the log.
- PostgreSQL 18 applies only to new local databases. An existing cluster is never upgraded.

### 🔐 Security
- The shipped systemd units now sandbox the panel. Only its own folders are writable, its capabilities are reduced, namespaces and address families are restricted, `UMask=0077` is set, and a `@system-service` seccomp filter is added on systemd 239 or newer ([#6718](https://github.com/MHSanaei/3x-ui/pull/6718)) @ChesterFishmansWork
- The repository's automated PR-review and issue-analysis workflows no longer hold write or OIDC tokens, so code checked out from a pull request cannot mint a write token ([`9130f6dd`](https://github.com/MHSanaei/3x-ui/commit/9130f6dd), [`5939fda3`](https://github.com/MHSanaei/3x-ui/commit/5939fda3), [`53239285`](https://github.com/MHSanaei/3x-ui/commit/53239285))

### 🆕 New
- MASQUE inbounds and outbounds: CONNECT-IP over HTTP/3 or HTTP/2, always behind TLS. Clients sign in with their email and password, and the JSON subscription builds each client's MASQUE outbound. Share links and Clash skip MASQUE because it has no link format ([`b04039c2`](https://github.com/MHSanaei/3x-ui/commit/b04039c2), [`00aaef38`](https://github.com/MHSanaei/3x-ui/commit/00aaef38), [`c4b9b3f9`](https://github.com/MHSanaei/3x-ui/commit/c4b9b3f9))
- The WARP modal can register a WARP device over MASQUE and turn it into a ready `warp-masque` outbound. Your existing WireGuard registration is left untouched ([`04cccef3`](https://github.com/MHSanaei/3x-ui/commit/04cccef3))
- XDRIVE transport on inbounds and outbounds: tunnel a stream through files in Google Drive, a local folder or an HTTP storage API described by a template. XDRIVE outbounds can use TLS to front the storage API, and storage settings Xray cannot open are refused when you save ([`ca598359`](https://github.com/MHSanaei/3x-ui/commit/ca598359), [`c7d89cea`](https://github.com/MHSanaei/3x-ui/commit/c7d89cea), [`c5e1e54c`](https://github.com/MHSanaei/3x-ui/commit/c5e1e54c))
- Lua DNS and routing scripts: DNS gets a script field and a per-server ID, Basics gets a routing script field, and the Routing tab warns that rules are skipped while a script is set ([`b6c859f5`](https://github.com/MHSanaei/3x-ui/commit/b6c859f5), [`73a028f5`](https://github.com/MHSanaei/3x-ui/commit/73a028f5))
- TUN inbounds can set the Windows adapter type, point systemd-resolved at the TUN gateway on Linux, and block DNS leaks through WFP on Windows ([`ef4bda4e`](https://github.com/MHSanaei/3x-ui/commit/ef4bda4e))
- The finalmask editor now covers more of the format: header-custom variables and transforms, a TCP `errors` group, UDP prefix/standalone mode, the sudoku UDP mask, and noise reset ranges such as `60-120`. These keys used to be dropped on save ([`1c050f87`](https://github.com/MHSanaei/3x-ui/commit/1c050f87))
- Outbound TLS has a *Use system CA* switch for servers signed by a privately installed CA ([`73a028f5`](https://github.com/MHSanaei/3x-ui/commit/73a028f5))
- New local PostgreSQL installs get PostgreSQL 18 from the official PGDG repository. Where PGDG has no build, the distro package is used instead ([`c9207b6f`](https://github.com/MHSanaei/3x-ui/commit/c9207b6f))
