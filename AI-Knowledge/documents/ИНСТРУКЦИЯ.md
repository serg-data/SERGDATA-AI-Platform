# Инструкция по локальной базе знаний SERGDATA

## 1. Для чего нужна база

База знаний хранит исходный код проектов, техническую документацию и собственные заметки. Локальная модель в LM Studio может искать в этих материалах через MCP.

Основная папка: `F:\AI-Knowledge`

## 2. Куда добавлять материалы

- `F:\AI-Knowledge\code` — исходный код и Git-репозитории.
- `F:\AI-Knowledge\documents` — документация, инструкции и заметки.
- `F:\AI-Knowledge\index` — служебная база SQLite. Не класть сюда документы вручную.

## 3. Как добавить новый Git-репозиторий

Открой PowerShell и выполни команду, заменив URL и имя проекта:

```powershell
git clone --depth 1 https://github.com/АВТОР/ПРОЕКТ.git "F:\AI-Knowledge\code\ИМЯ-ПРОЕКТА"
```

Пример для sing-box:

```powershell
git clone --depth 1 https://github.com/SagerNet/sing-box.git "F:\AI-Knowledge\code\sing-box"
```

Перед скачиванием убедись, что папки с таким именем ещё нет.

## 4. Как обновить существующие репозитории

```powershell
git -C "F:\AI-Knowledge\code\xray-core" pull --ff-only
git -C "F:\AI-Knowledge\code\passwall2" pull --ff-only
```

Для других проектов замени путь на нужную папку. Если Git сообщает об ошибке, не используй принудительный сброс и не удаляй изменения наугад.

## 5. Как добавить документацию

Скопируй файлы в:

`F:\AI-Knowledge\documents`

Для надёжной индексации используй текстовые форматы: `.md`, `.txt` или `.rst`. Исходники с поддерживаемыми расширениями можно размещать в `code`.

PDF и DOCX текущий индексатор напрямую не обрабатывает. Сначала извлеки текст и сохрани его в поддерживаемом формате.

## 6. Как обновить индекс

После добавления, изменения или обновления материалов выполни в PowerShell:

```powershell
& "C:\Users\user\AppData\Local\Programs\Python\Python312\python.exe" "F:\AI-Knowledge\kb.py" index
```

Индексатор пропускает неизменённые файлы и добавляет новые либо изменённые.

## 7. Как проверить поиск

Например, найти упоминания XHTTP:

```powershell
& "C:\Users\user\AppData\Local\Programs\Python\Python312\python.exe" "F:\AI-Knowledge\kb.py" search XHTTP
```

Несколько слов ищутся одновременно. Если результатов нет, попробуй другое ключевое слово.

## 8. Правила безопасности

- Не помещай пароли, приватные ключи, токены и другие секреты в базу.
- Не удаляй файлы из `index` вручную.
- Перед изменением `kb.py` или `server.py` делай резервную копию.
- После обновления исходников повторно запускай индексацию.
- Если MCP не работает, сначала проверь журнал и настройки LM Studio, а не пересоздавай базу.
