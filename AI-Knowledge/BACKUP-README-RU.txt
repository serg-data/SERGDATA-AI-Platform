SERGDATA — резервный чистовой снимок

Архив содержит очищенные файлы проекта, но не содержит локальную папку .git (в исходном архиве она была неполной и не являлась рабочим Git-репозиторием).
Для Git: распаковать в рабочую папку существующего клона либо выполнить git init, git add и git commit; удалённый origin настраивается отдельно.
AI-Knowledge является отдельной папкой/репозиторием. Не объединять её содержимое с корнем Workbench.
В Workbench встроенные ai-knowledge/kb.py, server.py и update-knowledge.ps1 синхронизированы с соответствующими файлами AI-Knowledge; корневая дублирующая копия update-knowledge.ps1 удалена.
Файл .env намеренно не включён: перенести собственный .env отдельно из защищённой резервной копии.
