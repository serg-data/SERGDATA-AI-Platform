Способ 1. Интерактивный выбор
Перейди в папку проекта F:\AI-Knowledge и выполни:
python kb.py index --select


Скрипт предложит выбрать:
- 1 — отдельный файл;
- 2 — папку вместе со всеми вложенными папками.
Затем введи путь к нужной папке. Например:
2
F:\AI-Knowledge\code\xray-core


Будут проиндексированы поддерживаемые файлы внутри выбранной папки.
Способ 2. Сразу указать папку
Например, проиндексировать только man-pages:
python kb.py index --path "F:\AI-Knowledge\code\man-pages"


Или только документацию Caddy:
python kb.py index --path "F:\AI-Knowledge\code\Caddy"


Путь должен находиться внутри F:\AI-Knowledge.
